Paste your Tinder X-Auth-Token (it changes each session). Used once to read your profile — never stored or logged.

How do I get my X-Auth-Token?
  1. Open tinder.com in your browser and log in.
  2. Press F12 → Network tab → filter for api.gotinder.com.
  3. Click any request → Headers → copy the value of X-Auth-Token.
  4. Paste it above. (Grab a fresh one if it expires.)
